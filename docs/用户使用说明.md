# 设计百宝箱 使用说明

设计百宝箱是给设计师用的离线小工具集。把文件放进指定文件夹，双击程序，选一个工具，然后去输出文件夹拿结果。

## 快速上手

1. 把文件放进程序旁边的 `input/` 文件夹：
   - 要压缩的 PDF 放进 `input/pdf/`
   - 要转 GIF 的 SVG/SVGA 放进 `input/svg/`
2. 双击运行程序：
   - macOS：`toolbox`
   - Windows：`toolbox.exe`
3. 在菜单里输入数字选择工具，按提示确认参数（直接回车使用推荐值）。
4. 处理完成后，到 `output/` 文件夹查看结果：
   - 压缩后的 PDF 在 `output/pdf/`
   - GIF 在 `output/svg/gif/`，APNG 在 `output/svg/apng/`

## 工具说明

### 1. PDF 压缩

适合压缩单页长图型 PDF（作品集、长图导出稿）。批处理时会先选择压缩档位：

| 档位 | 名称 | 说明 |
| --- | --- | --- |
| 1 | 推荐均衡（q40） | 适合提交和分享，通常能明显压小，同时保留可读性 |
| 2 | 清晰优先（q50） | 画质更稳，文件比推荐档稍大 |
| 3 | 更小文件（q30） | 适合严格大小限制，细节损失更明显 |
| 4 | 高质量（q84） | 接近原默认画质，文件相对更大 |

也可以输入多个质量一次生成多个版本，例如 `40,50,60`，或输入范围 `q10-q90`。

注意：仅支持单页、单主体图像的 PDF。多页 PDF、复杂矢量页面、加密文件无法处理。

### 2. SVG/SVGA 转 GIF

批量把 SVG（含 SMIL 动画）和 SVGA 动画文件转换成 GIF，同时输出 APNG 中间文件。批处理时可以输入帧率（直接回车为 20 FPS）。

转换模式自动选择：

- 程序旁边有 `ffmpeg`（或系统安装了 ffmpeg）时使用 ffmpeg，调色板质量更好；
- 没有 ffmpeg 时使用程序内置编码器，结果一样可用，单文件即可分发。

## 命令行用法（可选）

```
toolbox                      交互式主菜单
toolbox pdf                  批处理 input/pdf/ → output/pdf/
toolbox pdf -input a.pdf -output b.pdf [-quality 40] [-strip-height 16000]
toolbox svg2gif <source> <target> [-w 800 --height 800] [-f 20]
toolbox version              显示版本
```

## 常见问题

- **双击后窗口一闪而过**：说明 stdin 没有挂起。请先打开终端，把程序拖进终端再回车运行。
- **macOS 提示"无法验证开发者"**：右键点击程序选"打开"，或在"系统设置 → 隐私与安全性"里允许。
- **输出在哪里**：都在程序旁边的 `output/` 文件夹里，原始输入不会被修改或删除。

## 隐私

程序完全离线运行，不联网、不上传任何文件。你的 PDF 和图片只在本机处理。
